# 世界观发散 ·《回声循环》

这台发散引擎只做一件事：让脑洞从既有规则里长出来，而不是从天上掉下来。

## 一、可以被碰撞的规则（撞别的都不算）

- **角色位不可更换**：入场即分配角色位。角色位决定你能看见什么、能说什么、能走到哪；它不因你知道得更多而放宽。
- **结局收敛律**：副本必须回到它原本的结局。任何偏移都会被「世界重力」拉回，拉回过程造成的伤害记在玩家身上，而不是记在故事上。
- **记忆折价**：每重开一次，记忆按 15% 衰减。记得太多、且记得太清楚的人，会被判定为「异常」并被单独处理。
- **死亡即转职**：死在副本里的人不会离开，而是变成这个副本里的 NPC，被下一批玩家遇见。他们通常不记得自己曾经是玩家。
- **叙述者不可见**：副本里存在一个负责分配角色、修订台词的存在。它可以被听见、被推演，但不能被指认、被攻击、被拍照。
- **台词的重量**：在副本里说出的每一句完整的话都会被记录为「台词」。说错一句，后续场景随之改变；说出的话不能撤回，也不能重录。

## 二、当前的边界（写太远会变成另一个世界）

- 参考时间线：第一次副本 · 雨夜列车（入场第 1 夜 — 第 3 夜）
- 战力上限：没有超能力，只有角色位附带的权限：能查票、能报站、能在特定车厢停留三十秒。任何超出角色位的动作都会被「重力」纠正。
- 不可触碰：列车到站、玩家离开副本、沈雾想起他真正在找的那个人、叙述者被当面指认

## 三、本次种子

**如果小满知道自己是被生成的人格**（el-h2）

前提：她知道了。不是被告知，是自己推出来的——从一个不合时宜的口误开始，花了整整两轮。

既有的引导问题：
- 一个副本原住民知道自己是被写的，她会选择演完，还是选择让故事演不下去？
- 她的「知道」算不算偏离结局？重力会扳回她，还是扳回别人？
- 如果她拒绝再当第 4 节的乘客，那节车厢会变成什么？

## 推演框架 · 三阶蝴蝶效应（必须逐阶完成，不许跳阶）

**第一阶 · 直接规则碰撞**
问：这个 IF 正面撞上了哪一条铁律？谁先付出代价？
要求：
- 点名被触碰的规则（引用它的标题，不要泛泛而谈）
- 写出第一笔代价，且代价必须落在具体的人身上，不能写成"世界因此动荡"
- 判断这次碰撞是"可用"还是"立刻崩塌"：崩得太快就没有第二阶

**第二阶 · 既得利益势力反弹**
问：谁靠这条规则吃饭？他们会怎么反制？
要求：
- 至少两个势力，且诉求必须互相冲突（不能都反对、也不能都支持）
- 反制手段要具体：收买、封口、立法、涨价、断供、暗杀、册封
- 写出他们的第一步失误——没有失误的反派推不动故事

**第三阶 · 底层生态或叙事走向异变**
问：三年后，哪个日常细节被永久改写了？
要求：
- 落到普通人的生活：货币、婚配、教育、殡葬、语言、通勤
- 给出一个不可逆的变化（可逆的变化等于没变）
- 用一句"从此以后，人们……"收尾

## 四、交付协议

1. 输出 **3 条分叉**，每条必须包含以下五个字段，缺一个就算不合格：
   - 规则依据：撞的是哪条铁律（写标题）
   - 第一笔代价：谁先付、付了什么
   - 既得利益者：谁反制、用什么手段
   - 三年后的日常：一个不可逆的生活细节变化
   - 不可逆点：这条分叉之后再也回不去的地方
2. 每条分叉后用一行标明风险：安全 / 擦边 / 越界（越界需说明触碰了哪条黑名单）。
3. 不要复述本框架，不要写「首先我认为」这类过渡句，直接给分叉。
4. 如果用户想要一条「爽但违规」的分叉，先给出违规版本，再给出一个规则内的等价版本，并说明差异。
