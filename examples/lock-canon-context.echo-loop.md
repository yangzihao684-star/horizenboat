# 原著宪章锁定 ·《回声循环》

work_id = echo-loop  ·  timeline_id = t1  ·  角色 2 位
时间线：第一次副本 · 雨夜列车（入场第 1 夜 — 第 3 夜）  ·  铁律 6 条  ·  黑名单 3 条

## 一、世界铁律（违反任一即崩设定）

1. **角色位不可更换**：入场即分配角色位。角色位决定你能看见什么、能说什么、能走到哪；它不因你知道得更多而放宽。
   - 写法要求：写副本时必须先写清「他拿的是谁的位置」。角色位之外的信息，只能通过别人的嘴、纸条或残缺的录音得到，且必须付出代价。
2. **结局收敛律**：副本必须回到它原本的结局。任何偏移都会被「世界重力」拉回，拉回过程造成的伤害记在玩家身上，而不是记在故事上。
   - 写法要求：你想救人，可以；但那笔账必须有人付。每一次偏离都要写清「世界如何把它扳回来」——用谁的手、用多长的时间。
3. **记忆折价**：每重开一次，记忆按 15% 衰减。记得太多、且记得太清楚的人，会被判定为「异常」并被单独处理。
   - 写法要求：重开的次数要可数；第 N 次重开后，角色必须丢掉一些具体的细节（名字、脸、气味），不能只是「有点模糊」。
4. **死亡即转职**：死在副本里的人不会离开，而是变成这个副本里的 NPC，被下一批玩家遇见。他们通常不记得自己曾经是玩家。
   - 写法要求：任何一个 NPC 都可能是上一个死人。写 NPC 时要留一处不协调的细节——用过的手表、说错的年代、下意识的动作。
5. **叙述者不可见**：副本里存在一个负责分配角色、修订台词的存在。它可以被听见、被推演，但不能被指认、被攻击、被拍照。
   - 写法要求：任何人试图直接指认它，都会在说出口的瞬间被替换成一句无关的日常台词。这条规则不能被绕过，只能被绕开。
6. **台词的重量**：在副本里说出的每一句完整的话都会被记录为「台词」。说错一句，后续场景随之改变；说出的话不能撤回，也不能重录。
   - 写法要求：对话要先听后说。写玩家开口前，先写他听见了什么；一句台词落地后，必须有一个人因此改变站位、语气或决定。

## 二、时间线边界

**当前世界局势**

一列永远开不到站的夜车，六节车厢，十二个乘客。沈雾被分到的角色位是「查票的」——一个没人愿意当、却必须走遍每节车厢的位置。窗外是雨，没有风景。

**战力上限**：没有超能力，只有角色位附带的权限：能查票、能报站、能在特定车厢停留三十秒。任何超出角色位的动作都会被「重力」纠正。

**角色此刻的认知边界**
- 沈雾只知道自己的角色位任务，不知道这趟车原本的结局。
- 他不知道前面几节车厢里有几个是活人。
- 老周知道得比他多，但不说；售票员 07 说的每一句都像真话，也像钩子。

**未发生事件黑名单（防剧透 / 防吃书）**
- ✗ 列车到站、玩家离开副本 —— 这是第一幕的终点，提前到站会让整条时间线失去张力。
- ✗ 沈雾想起他真正在找的那个人 —— 记忆是这部作品的主线货币，第一卷只能给到「有个轮廓」。
- ✗ 叙述者被当面指认 —— 违反「叙述者不可见」铁律，且会提前耗尽悬疑。

## 三、角色钢印

### 1. 沈雾（主角 · 第一次入场）

- 途径 / 位阶：角色位：查票的（第一副本）→ 住在这里的人（第五副本）
- 别称：查票的、06
- 核心驱动力：找到一个人。他不记得她的名字、长相、关系，只记得自己必须找到她——这件事比活下去更硬。

**性格内核**
- 先听，再说。开口前会在心里把话过一遍。
- 对规则极其敏感，但从不解释自己为什么敏感。
- 不擅长安慰人，擅长记住别人说错的细节。
- 在必须说谎的时候会说得非常短。

**语言习惯（speech_pattern）**
句子短，常用陈述句，很少用形容词；问句多为单句追问。紧张时不提高音量，而是把句子越说越短。

**称呼矩阵（不得串用）**
- 对 售票员 07 → 「你 ／ 07」（从不叫「你好」）
- 对 老周 → 「老周」
- 对 小满 → 「小满」（叫得比其他人轻一点）
- 对 陌生人 → 「先生 ／ 女士」

**台词钢印（保持语域，不要逐字照搬）**
- 正典：「票。」
- 正典：「这一节车厢的人比上一节少一个。你们谁动过座。」
- 正典：「我不需要你告诉我结局。我只需要知道，这趟车上一共死过几个人。」
- 语域锚点：「……算了。你先说。」

**绝对禁止（OOC）**
- ✗ 开挂式破局：无视角色位权限行动
- ✗ 情绪外放：哭喊、咆哮、长篇独白
- ✗ 突然变成解说员，把规则一次性讲透
- ✗ 使用网络流行语或现代梗

### 2. 小满（副本原住民 · 不知道自己是谁）

- 途径 / 位阶：角色位：乘客（第 4 节固定座）
- 别称：丫头、第 4 节
- 核心驱动力：想知道窗外是什么。这个问题她已经问了很久，久到不像一个乘客。

**性格内核**
- 问问题不问分寸，被凶了也不怕。
- 对「死亡」没有概念，只对「下车」有概念。
- 偶尔会说出一句只有老玩家听得懂的话。

**语言习惯（speech_pattern）**
语速快，句子长，一口气问两三个问题；用词偏孩子气，但偶尔冒出精确到年份的表述。

**称呼矩阵（不得串用）**
- 对 沈雾 → 「查票的」（她只按角色位叫人）
- 对 老周 → 「老爷爷」
- 对 售票员 07 → 「叔叔」

**台词钢印（保持语域，不要逐字照搬）**
- 正典：「查票的，窗外为什么一直是雨？我坐了很久了。」
- 正典：「你身上有股味道，像很久以前的车厢。」
- 正典：「我不怕死。我只怕一直坐在这里。」

**绝对禁止（OOC）**
- ✗ 突然意识到自己是 NPC 并理性分析
- ✗ 说出超出其年代的信息

## 四、文风约束

- 叙述声音：冷、克制、留白。第三人称限知，几乎不用感叹号；恐怖来自「不对劲」而不是「吓一跳」。
- 节奏：每个场景只交代必要信息，把解释权留给读者；对话短，动作准，环境用一两个细节定调就够。
- 禁用词：绝绝子、yyds、破防、家人们、刺激、吓死宝宝了
- 固定术语：角色位 —— 统一用「角色位」，不用「身份」「职业」
- 固定术语：副本 / 后台 —— 玩家所在的地方叫副本，死亡后的地方叫后台
- 固定术语：重开 —— 不说「复活」，因为并没有人活过来
- 用编号代替名字：07、13、'那个人'。名字本身就是稀缺资源。
- 禁止出现「系统提示」「叮，恭喜宿主」这类网文装置。
